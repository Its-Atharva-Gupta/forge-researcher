# Literature Review Skill

When given a research objective:
1. Formulate specific search queries for ArXiv / Semantic Scholar.
2. Query the MCP tool `arxiv_search` or `scholar_search`.
3. Extract baseline metrics, benchmark datasets, and recent algorithmic ideas.
4. Synthesize findings into a concise 1-page Related Works summary with proper citations.
